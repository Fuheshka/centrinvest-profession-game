# Жёлтые стикеры с креплениями ниток

Три варианта по приложенному автором жёлтому стикеру. Встроенный image_gen, прозрачный PNG, без текста.

- `sticker-two-side-ports.png`: крепления по центру левой и правой сторон.
- `sticker-four-edge-ports.png`: крепления сверху, снизу, слева и справа.
- `sticker-double-side-ports.png`: по два крепления на каждой боковой стороне.

Чёрная частая сетка из снимка редактора убрана; жёлтая бумага, коричневая кнопка и загнутый угол сохранены как мотив исходника. Между креплениями в спрайт не запечены нитки: их форму должен менять UI при перемещении карточек.
Положение якорей префаба подбирать по центрам креплений выбранного варианта; не предполагать одинаковые отступы у всех рисунков.

План адаптивных кривых: `docs/ROADMAP.md`, раздел «Запланировано: стикеры с креплениями и изогнутые нитки» от 2026-10-24.
Точные промпты: `docs/art-source/sticker-connectors-2026-10-24/prompts.json`.
Статус: ждёт проверки командой. Кривые и подключение в префабы в этой задаче не реализованы.
