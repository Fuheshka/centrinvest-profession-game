# Набор UI-спрайтов «Билд к пятнице»

Источник: восемь макетов `docs/mockup/generated-2026-10-24/`.
Графика сгенерирована встроенным image_gen, затем нарезана и упакована по категориям.
Статус: ждёт проверки командой. В сцены и префабы не подключена.

## Категории

| Папка | Листы | Содержимое | Ячейка итогового листа |
|---|---|---|---|
| Icons | icons-navigation, icons-concept, icons-actions | Навигация, ресурсы, типы концепта, файлы, действия | 256 × 256 |
| Buttons | buttons | Четыре семейства кнопок, по четыре состояния | 512 × 192 |
| Avatars | avatars | Борис, Лера, Костя, Аня, Вика, Дима, Гоша и лис-персонаж; обычные и уставшие | 512 × 512 |
| Panels | panels | Подложки рабочего окна, сайдбара, шапки, модалки, заголовка, подсказки и уведомлений | 512 × 384 |
| Cards | cards | Концепт, задачи, вложение, кандидат, входящее и исходящее сообщения | 512 × 384 |
| Controls | controls | Полоски, переключатели, чекбоксы, радио, скролл, бейдж | 256 × 160 |
| Decor | decor | Звёзды, луна, записка, папка, трофей, космос, лис и растение | 256 × 256 |
| Backgrounds | backgrounds | Студия днём и ночью, бордовый фон, светлый холст | 1024 × 768 |

В каждой категории `*-sheet.png` – ровная сетка для Sprite Mode Multiple.
Одноимённая подпапка содержит отдельные именованные PNG – альтернативный вариант импорта.
Не требуется одновременно использовать в сценах и лист, и отдельные PNG.
Имена, порядок, точные прямоугольники и рекомендуемые границы 9-slice находятся в `manifest.json`.
Координаты в manifest – от левого нижнего угла, как в Unity; порядок имён – слева направо, сверху вниз.

## Подготовка в Unity

1. Для отдельного PNG: Texture Type = Sprite (2D and UI), Sprite Mode = Single. Для листа: Multiple.
2. Для листа в Sprite Editor: Slice → Grid By Cell Size, размер из таблицы; Offset и Padding = 0.
3. Alpha Is Transparency = On, Mip Maps = Off, Wrap Mode = Clamp, Mesh Type = Full Rect, PPU = 100.
4. Max Size должен вмещать размер из manifest: например, лист аватаров 2048 × 2048. Для исходного качества Compression = None.
5. Для аватаров и пиксельного декора начните с Point; для плавных панелей и кнопок – Bilinear. Проверьте читаемость на фактическом размере UI.
6. Кнопки: Sprite Swap. Столбцы листа – normal, hover, pressed, disabled; для четвёртой строки третий столбец – selected.
7. Панели и кнопки: Image Type = Sliced. Границы из manifest предварительные; проверьте растяжение углов и тени в Sprite Editor. Карточки с портами, хвостами и внутренним окном требуют отдельной проверки при изменении пропорций.
8. Шкалы: отдельный track и полноширинный fill, Image Type = Filled / Horizontal. Энергию и прогресс задач заполняет UI из состояния игры.

Надписи, числа, имена, роли, статусы и цены добавляются отдельным TextMeshPro. Для текста уже есть FindSansPro-Bold и VcrOsdMonoCyr в `Assets/_Project/Art/Fonts/`. PNG кнопок и карточек текста не содержат.
Изображения фонов имеют пропорцию 4:3; для окна 16:9 выбирайте кадрирование или отдельный фон нужной пропорции, не растягивайте иллюстрации непропорционально.

## Исходники и воспроизводимость

Исходные листы, промпты и скрипт упаковки: `docs/art-source/ui-kit-2026-10-24/`.
Запуск из корня: `python3 docs/art-source/ui-kit-2026-10-24/package_sheets.py` (Pillow).
Скрипт находит прозрачные промежутки, нарезает, сохраняет alpha и размещает спрайты с отступом в фиксированных ячейках. Он не перерисовывает иллюстрации.
Импорт в Editor, состояние кнопок и растяжение в префабах требуют проверки при сборке UI; здесь подготовлены растровые файлы и карта нарезки.
