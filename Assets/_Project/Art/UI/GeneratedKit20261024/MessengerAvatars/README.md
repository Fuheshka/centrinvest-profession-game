# Пиксельные аватарки для мессенджера

Пять самостоятельных квадратных PNG по мотивам референсов автора:

- `goose-messenger.png` – гусь с оливковым платком;
- `wizard-frog.png` – лягушка в шляпе мага;
- `surprised-giraffe.png` – удивлённый жираф в очках;
- `peach-lovebird.png` – яркая птица в наушниках;
- `mint-alien.png` – зелёный пришелец.

Размер каждого исходника 1254 × 1254. Фон шоколадный, как у примеров автора; дополнительная подложка не требуется. При импорте в Unity использовать Sprite (2D and UI), Single, Point, Mip Maps off. Проверить вид на размере 48 × 48 и круглую маску, если она используется в префабе.

Это варианты на выбор команды, игровым персонажам они ещё не назначены. Существующие портреты находятся в соседней папке `Avatars/`.
Обзор крупного и малого размера: `docs/art-source/messenger-mascots-2026-10-24/overview.png`.
Промпты и пять приложенных референсов: `docs/art-source/messenger-mascots-2026-10-24/`.
