# Кейс «Центр-инвест»: разработка игры

Источник: `case/case-centrinvest.pdf`. Призовой фонд 100 000 ₽. Эксперты: Артём Цапков (Unity-разработчик, Try Hard Games), Михаил Карасев (HR, банк «Центр-инвест»).

**Цель.** Подросток до 16 лет выбирает, кем быть, и мало знает о профессиях. Игра даёт погрузиться в одну выбранную профессию.

## Обязательно

- [ ] Браузерная версия: открыть страницу, запустить, пройти полную сессию.
- [ ] Без регистрации (почта, телефон и т.п.); можно спросить никнейм.
- [ ] Завершённый кусок геймплея: один уровень или одна глава, видны идея и основные механики.
- [ ] Понятная концепция, логически связанные персонажи, сюжетная линия.
- [ ] Нет критических багов, мешающих сессии.
- [ ] Масштабируемость: место для новых сюжетов и механик.
- [ ] Уникальность: механики и геймдизайн, которых нет у игр той же темы.

## Со звёздочкой

- [ ] Сохранение прогресса.
- [ ] Несколько уровней сложности.

## Презентация

- [ ] Стек.
- [ ] Команда и роли.
- [ ] Концепция и что из геймплея сделано.
- [ ] Скриншоты визуального стиля.
- [ ] Референсы (игры-вдохновители).
- [ ] QR-коды на игру и на репозиторий.

## Критерии оценки

1. Играбельный прототип: быстро запускается, полная сессия.
2. Завершённость: идея, сюжет и механики видны.
3. Цель кейса: игра даёт представление о профессии.
4. Тестирование: без крашей и критических багов.
5. Презентация: полная, вся нужная информация.
