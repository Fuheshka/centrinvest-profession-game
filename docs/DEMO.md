## Системы в Unity

Логика – чистый C# в `Studio.Core` с EditMode-тестами (TDD). UI читает `LevelState` и вызывает операции. Контракты – `ROADMAP.md`, «Контракты MVP».

| Система | Что делает | Роль |
|---|---|---|
| `LevelState`, `SaveSystem` | состояние уровня, JSON, `save_v2` | Р1 |
| `ConceptRules` | блоки, линии, бафы, утверждение, задачи | Р2 |
| `WorkSim` | время, работа, энергия, ночь, оплата, файлы, дедлайн | Р1 |
| `Staffing` | ставки и найм | Р2 |
| `Review` | сборка, оценка, отзыв, исправление, тупик бюджета | Р2 |
| `LevelSO` | все данные и числа уровня | Р1 (тип), Р2 (контент) |

Сцены: `Menu` и `Game` (окна чата, дэшборда, хедхантера, таск-листа; модальные отзыв, ночь, итог).
