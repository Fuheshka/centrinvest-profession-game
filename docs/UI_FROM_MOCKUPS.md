# UI по макетам 2026-10-24: промпты и пробелы

Дата: 2026-10-24. Статус: план; UI-1 и UI-2 сделаны (см. `STATE.md`). Решения автора 2026-10-24: ночь остаётся вырезанной, вкладка зовётся «Хедхантер».
Источник макетов: `docs/mockup/generated-2026-10-24/01…08` (в папке Codex лежат те же 8 макетов, 14 листов набора и 3 стикера; новых файлов там нет, всё уже в репо: макеты, `Assets/_Project/Art/UI/GeneratedKit20261024/`, `docs/art-source/`).
Цель: собрать в Unity внешний вид, похожий на макеты, на текущем `MvpScreen`, без переписывания логики MVP.

## 1. Что уже есть

- Макеты 8 экранов, набор из 137 PNG (иконки, кнопки, аватары, панели, карточки, контролы, декор, фоны), 3 стикера с портами, шрифты FindSans и VCR OSD Mono, рабочий MVP (меню, дэшборд, хедхантер, таск-лист, чат, отзыв, финал; тесты 150/150).
- Заготовки UI-слоя: `Scripts/UI/Mvp/*`, префабы `Prefabs/UI/Mvp/`, генератор `Editor/MvpUiBuilder.cs`.

## 2. Чего не хватает

### 2.0 Пиксельные аватарки мессенджера (вариант на выбор команды)

Автор предложил использовать забавных пиксельных зверьков и персонажей по приложенным референсам. После уточнения автора подготовлены пять **новых персонажей** в том же малом пиксельном формате 200 × 200: кот, аксолотль, капибара, енот, гриб. Итоговые PNG и общий обзор – `Assets/_Project/Art/UI/GeneratedKit20261024/MessengerAvatarsPixel/` (`*_200.png` и `preview.png`). Более ранние варианты в `MessengerAvatars/` не соответствуют уточнённому стилю и оставлены только как история итерации.

При сборке чата Р3: проверить, читаются ли они в списке диалогов и пузырях на размерах 48 × 48 и 96 × 96, не обрезаются ли в круглой маске, различаются ли собеседники без чтения имени. Команда выбирает, кому из игровых персонажей назначить такие аватарки; до этого существующие портреты Бориса и сотрудников остаются доступным вариантом. Связать выбранный спрайт с конкретным собеседником через данные/инспектор, а не менять аватар всем чатам сразу. Статус: пять PNG готовы, визуальный размер 48 × 48 проверен на обзорном листе; решение о применении в UI не принято.

## 4. Карточки задач (для вставки в `PROMPTS.md`)

Каждая карточка: ветка `ui-N-короткое-имя` от `dev`, PR в `dev`, один коммит (docs и DEVLOG внутри), скриншот в `docs/progress/<feature>/`, тесты не ломать. Редактировать только префабы, сцены, `Scripts/UI`, `Editor`; логику Core не трогать.

### UI-1. Импорт набора и шаблоны (Sonnet, medium)
Цель: набор спрайтов готов к использованию в префабах.
Сделать: Editor-скрипт `UiKitImport.cs`: для всех PNG из `GeneratedKit20261024/*/*/` выставить Sprite (2D and UI), Single, Alpha Is Transparency, Mip Maps off, Clamp, Full Rect, PPU 100, Point для аватаров/иконок/декора и Bilinear для кнопок/панелей; `spriteBorder` из `manifest.json`. Собрать префабы `Prefabs/UI/Kit/`: ButtonPrimary, ButtonSecondary, ButtonOlive, Tab (Sprite Swap по четырём состояниям), Panel (ivory, olive, dark), ProgressBar (track + Filled fill, цвета green/amber/red), Toggle, Badge, Chip.
Не трогать: Core, текущие экраны. Готово: префабы Kit лежат в сцене-песочнице, стыки углов без искажений на размерах 120×40 и 600×80, скриншот.
