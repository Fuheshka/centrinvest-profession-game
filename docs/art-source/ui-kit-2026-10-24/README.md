# Исходники набора UI

Промпты всех основных листов: `plan.json` (общая часть `common` + поле `spec` соответствующего листа).
Дополнительные служебные значки: `extra-plan.json`, та же общая часть.
Встроенный image_gen, референс стиля – `docs/mockup/generated-2026-10-24/03-tasks.png`.
Все листы, кроме `backgrounds.png`, запрошены с `transparent_background: true`.

PNG здесь – неизменённые результаты генерации. Версии `-v2` хранятся отдельно и имеют приоритет при упаковке.
Точные размеры исходников определяет результат инструмента; упаковщик нормализует итоговые ячейки.

`package_sheets.py` нарезает листы по прозрачным промежуткам около границ сетки, сохраняет отдельные PNG и собирает ровные сетки. Фоны нарезаются по квадрантам.
Исходные прозрачность и рисунок сохраняются; уменьшение при необходимости выполняется Pillow.

Результат: `Assets/_Project/Art/UI/GeneratedKit20261024/`.
Карта спрайтов: `manifest.json` в папке результата.
Предупреждения упаковщика требуют проверки перед использованием спрайта.
