# Исходники аватарок мессенджера

Пять аватарок сгенерированы встроенным image_gen, по одной на каждый из пяти референсов автора. Референсы использованы как указатели стиля, новые персонажи нарисованы отдельно. Результат сохранён в `Assets/_Project/Art/UI/GeneratedKit20261024/MessengerAvatars/`.

- `prompts.json` – общий промпт и описание каждого персонажа;
- `references/` – исходные изображения, приложенные автором;
- `overview.png` – обзор результата в крупном и уменьшенном до 48 пикселей виде.

PNG сгенерированы с непрозрачным тёмно-коричневым фоном, визуально проверены на 48 пикселях. Решение о назначении персонажам мессенджера остаётся у команды, см. `docs/UI_FROM_MOCKUPS.md`.
