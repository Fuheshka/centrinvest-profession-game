# Журнал разработки

Что сделано и как проверено, по задаче на запись. Только дописывать в конец, старые записи не править. Отсюда берётся презентация.

Статусы: **сделано** (код есть, собирается, тесты зелёные) · **проверено агентом** (видно в запущенной игре: скриншот, проба) · **ждёт проверки командой** (по умолчанию для визуала и ощущений). Никогда не писать «принято командой» за команду.

Шаблон:

```
## 2026-10-23 · Короткое название
- Что работает: одна-три строки глазами игрока.
- Проверка: тесты (N/N), проверка в браузере, что не проверено.
- Статус: сделано | проверено агентом | ждёт проверки командой
- Коммит: заголовок коммита
- Скриншот: docs/progress/<feature>/<файл>.jpg (если видно в игре)
```
