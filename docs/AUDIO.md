# Звук и музыка

Что нужно для демо, где искать, как сдавать. Владелец – звуковик команды (карточка Н-2 в `NONCODE.md`). Встраивают в Unity разработчики: каждый для своего экрана (`TEAM.md`).

## Общий звук игры

Уютный офис вечером: мягко, тепло, немного игрушечно. Без резких «казуальных» бзынь и без кино-драмы. Всё – короткое (UI-звуки до 0.3 с), чтобы не надоедало за 25 минут: самые частые звуки (клик, сообщение) – в 2–3 вариантах, игра выбирает случайный.

## Музыка (6 треков)

Все треки бесшовно зацикливаются, без вокала (поверх много текста). Длина петли 1.5–3 минуты.

| Файл | Где играет | Настроение | Темп | Что искать (теги) |
|---|---|---|---|---|
| `mus_menu` | меню | вечер, уют, «сейчас начнётся» | 75–90 | lo-fi, chillhop, evening, cozy, rhodes piano |
| `mus_idea` | этап 1, доска | любопытство, лёгкость, игра с идеями | 90–100 | playful, curious, marimba, pizzicato, light lo-fi, puzzle |
| `mus_production` | этап 2, чат | рабочий драйв, «всё горит, но весело» | 100–115 | upbeat, workplace, chiptune lo-fi, office, management game |
| `mus_crunch` | этап 2–3, когда до дедлайна ≤ 3 дня | то же, но плотнее и тревожнее | 115–125 | tension, ticking, deadline, driving, synth pulse |
| `mus_release` | этап 3, версии | собранность, ожидание вердикта | 95–110 | focused, anticipation, minimal, electronic |
| `mus_ending` | финал | тёплая развязка (одна для всех концовок, стингер задаёт исход) | 80–95 | uplifting, warm, credits, soft victory |

Референсы по ощущению: Game Dev Story и Game Dev Tycoon (тема), Two Point Hospital (юмор), Mini Metro (минимализм), Hypnospace Outlaw (интерфейс как мир), A Short Hike (уют).

Переходы: при смене этапа – кроссфейд 1.5 с. `mus_crunch` можно заменить слоем поверх `mus_production` (если трек делится на стемы).

## Как сдавать

- Формат: WAV 44.1 кГц для звуков, WAV или OGG для музыки. Unity сам сожмёт для Web.
- Громкость: музыка около -16 LUFS, звуки нормализованы так, чтобы клик не был громче пинга сообщения. Тишину в начале и конце файла обрезать.
- Папки: `Assets/_Project/Audio/Music/`, `Assets/_Project/Audio/SFX/<группа>/` (ui, msg, day, board, prod, release, end, amb). Имена – как в таблицах.
- Вес: всё аудио вместе до 8 МБ в сборке (иначе Web долго грузится): музыку в Unity – Vorbis, качество 50–60, Load Type Streaming.
- Каждый файл – строка в `docs/CREDITS.md`: файл, источник (ссылка), автор, лицензия. Без строки файл в игру не идёт.
