# Паттерны движения и шаблоны промптов для 2D-анимации

Справочник проверенных таймингов, классификации предметов и формулировок промптов для покадровой анимации игровых спрайтов.

---

## 1. Сетка таймингов по типам действий

| Действие | Обычное число кадров | Амплитуда силуэта | Характер движения |
|---|---|---|---|
| **Атака оружием / ближний бой** | 14-21 | Расширение в 1.5-1.6x | Стойка -> замах -> ускорение -> удар (контакт) -> задержка -> возврат |
| **Idle (покой / дыхание)** | 14-21 | Колебания 3-5% | Плавный подъем груди/плеч, покачивание оружия, стабильные стопы |
| **Move / Walk (ходьба)** | 12-18 | Расширение около 15-20% | Контакт стопы -> приседание -> перенос веса -> подъем -> противоположный контакт |
| **Блок (Block / Parry)** | 10-14 | Минимальное сжатие | Подъем щита/оружия перед корпусом, фиксация ног, напряжение стойки |
| **Получение урона (Hit / Suffer)** | 12-16 | Откат назад | Ударная деформация (squash), откат корпуса назад, смещение центра, возврат |
| **Смерть (Death)** | 12-24 | Сжатие до земли | Потеря равновесия -> падение -> контакт с полом -> оседание (без зацикливания) |
| **Каст магии (Skill / Cast)** | 16-24 | Расширение силуэта | Концентрация магии -> воздетые руки -> вспышка -> остаточный шлейф |

---

## 2. Конструктор фаз удара (Beat Structure)

Стандартная боевая анимация строится по 6 ключевым битам:
1. **Neutral guard:** исходная устойчивая поза из кадра `00`.
2. **Anticipation (кадр 02):** замах оружия назад или вверх, приседание, отвод корпуса для накопления энергии.
3. **Acceleration (кадры 03-04):** быстрое движение вперед, смаз траектории.
4. **Contact (кадр 05):** максимальный выпад, пиковое раскрытие силуэта, точка соприкосновения с врагом.
5. **Follow-through & Hold (кадры 06-08):** проводка лезвия по инерции и короткая пауза в пиковой точке.
6. **Recovery (кадры 09-12):** возвращение руки и корпуса в базовую стойку.

Промпт-шаблон:
```text
Attack flow: neutral guard -> anticipation wind-up -> explosive forward acceleration -> impact contact -> follow-through hold -> balance recovery.
The contact frame (Keyframe 2) must have the widest, most readable silhouette.
Maintain exact foot baseline contact with the ground throughout all frames.
```

## 3. Классификация и фиксация экипировки (Prop Taxonomy)

Перед составлением промпта все предметы делятся на 4 категории:

| Категория | Значение | Правило для промпта |
|---|---|---|
| **Active Weapon** | Оружие удара (меч, топор, посох, лук) | Жестко привязано к `weaponHand`, не меняет руку, не дублируется |
| **Carried Prop** | Предмет в руке (факел, зелье, свиток, щит) | Привязано к свободной руке (`screen-left`), следует за корпусом |
| **Passive Accessory**| Элементы брони, плащ, рога, хвост | Крепятся к телу, могут развеваться, но не превращаются в оружие |
| **Detached Prop** | Снаряд, брошенный кинжал, стрела | Отделяется от персонажа строго в указанном кадре вылета |

Шаблон фиксации:
```text
prop taxonomy:
- activeWeapon: screen-right one-handed broadsword held firmly in screen-right hand.
- carriedProp: screen-left round wooden shield anchored to screen-left forearm.
- passiveAccessory: red shoulder cape following body inertia, dragon horns attached symmetrically to skull.
- detachedProp: none. Do not detach, duplicate, or mirror any item.
```
